# 表情包转换器 (Emoji Converter)

解决各平台客户端（如手机端 QQ）无法保存特定格式表情包的痛点。一键将内建表情包提取并转换为通用的图片格式。

## ✨ 功能简介
打破平台封锁，将心仪的表情包化为己有。无论是被客户端加密限制的静态贴纸，还是特殊的动态表情，都能轻松解析。
- **内存直发纯文件**：通过 Base64 直发实体文件卡片，避免二次压缩。
- **动态 WebP 自动转 GIF**：完美还原动图帧率、时长与透明通道。
- **私聊自动转文件（可配置）**：开启后，私聊收到表情包直接转换为文件发送，免输指令。
- **逐条转发多表情智能识别**：支持从其他聊天逐条批量转发多个表情包后，自动回溯转换或指令批量提取。

## ⚙️ 配置说明
在 AstrBot 管理面板的插件配置中提供以下选项：
- `auto_convert_private` (私聊收到表情包自动转换为文件)：默认 `false`，开启后私聊接收表情包即刻自动发送转换文件。
- `convert_animated_webp_to_gif` (动态 WebP 转为 GIF)：默认 `true`，沿用动图 WebP 转标准 GIF 的设定。

## ⌨️ 指令说明
- `/表情转换`：提取表情并发送为文件卡片。
  - 支持直接引用/长按回复目标表情包。
  - 支持发图同时配上文字 `/表情转换`。
  - 支持从其他聊天批量转发多张表情后，直接发送 `/表情转换`（自动按序回溯转换）。
- `/表情转存`：直接存入机器人的本地个人相册，便于后续查看和调用。
- `/表情相册 [页码]`：分页查看个人相册中的表情列表。
- `/表情相册发送 <序号>`：从个人相册中提取并发送指定序号的表情文件。
- `/表情相册删除 <序号>`：从个人相册中删除指定序号的表情。
